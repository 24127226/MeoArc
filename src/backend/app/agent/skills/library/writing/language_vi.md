# Văn phong tiếng Việt

## Tổng quan
Tiếng Việt có hệ thống xưng hô phức tạp dựa trên tuổi tác, thâm niên, và mối quan hệ. Sai xưng hô có thể khiến email trở nên thiếu tôn trọng hoặc quá xuồng xã. Skill này hướng dẫn chọn đại từ xưng hô, sử dụng kính ngữ, và format email chuẩn tiếng Việt.

## Khi nào dùng
- Soạn email bằng tiếng Việt
- Trả lời email mà người gửi viết bằng tiếng Việt
- Người dùng yêu cầu "viết email tiếng Việt"
- Cần chọn xưng hô phù hợp với đối tượng nhận

**Không dùng** khi email hoàn toàn bằng tiếng Anh.

## Chọn xưng hô

```
                    ┌─────────────────────────┐
                    │ Đối tượng nhận là ai?   │
                    └────────────┬────────────┘
                                 │
              ┌──────────────────┼──────────────────┐
              ▼                  ▼                  ▼
     ┌────────────────┐ ┌────────────────┐ ┌────────────────┐
     │ Giảng viên /   │ │ Đồng nghiệp /  │ │ Bạn bè / người │
     │ Cấp trên /     │ │ Bạn cùng lớp / │ │ thân thiết     │
     │ Khách hàng     │ │ Đối tác ngang  │ │                │
     └───────┬────────┘ └───────┬────────┘ └───────┬────────┘
             │                  │                  │
             ▼                  ▼                  ▼
     ┌────────────────┐ ┌────────────────┐ ┌────────────────┐
     │ Thầy/Cô + ơn   │ │ Em/anh/chị +   │ │ Tớ/mình/bạn   │
     │ Dạ/thưa đầu    │ │ nhờ/vui lòng   │ │ Thoải mái, tự  │
     │ câu            │ │                │ │ nhiên          │
     └────────────────┘ └────────────────┘ └────────────────┘
```

### Bảng xưng hô

| Đối tượng | Người viết → Người nhận | Ví dụ mở đầu |
|-----------|------------------------|--------------|
| Giảng viên / Giáo sư | Em → Thầy/Cô | `Thưa Thầy,` / `Em chào Cô ạ,` |
| Cấp trên / Sếp | Em → Anh/Chị | `Anh Nam,` / `Chị Lan,` |
| Khách hàng / Đối tác lớn | Em/Chúng tôi → Anh/Chị | `Kính gửi Anh/Chị,` |
| Đồng nghiệp cùng cấp | Mình/Tớ → Bạn | `Chào bạn,` / `Hi Nam,` |
| Bạn thân / nhóm thân | Tao → Mày | `Mày ơi,` (chỉ trong chat, không email) |
| Không rõ / trang trọng | Tôi → Anh/Chị | `Kính gửi Anh/Chị,` |

**Quy tắc vàng:** Khi không chắc, chọn xưng hô TRANG TRỌNG hơn một bậc. Anh/Chị an toàn hơn bạn.

## Kính ngữ và sắc thái

### Các từ nên dùng trong email trang trọng
- `Kính gửi` — mở đầu thư trang trọng
- `Trân trọng` — kết thư (tương đương "Best regards")
- `Vui lòng` / `làm ơn` — thay cho "please"
- `Xin phép` / `xin phép được` — khi đề nghị
- `Rất mong` — khi yêu cầu
- `Kính chúc` — lời chúc

### Các từ tránh trong email
- `Mày / tao` — chỉ dùng trong chat thân mật, không dùng trong email
- `Cứ bảo nhé` — quá suồng sã cho email công việc
- `Ok / ukm / vâng ạ` thiếu dấu — viết hoa đầy đủ "Vâng ạ"
- Viết tắt tin nhắn: `k, ko, dc, đc` — viết đầy đủ "không", "được"

## Format chuẩn

```html
Kính gửi Thầy [Tên],

Em là [Tên] — sinh viên lớp [Lớp]. Em viết thư này để [mục đích].

[Nội dung chính — ngắn gọn, bullet point nếu có nhiều ý]

Em rất mong nhận được phản hồi từ Thầy trước [ngày].

Trân trọng,
[Tên đầy đủ]
[Mã số sinh viên]
[Lớp]
```

### Format thân thiện hơn

```html
Chào [Tên],

Tớ viết email này để hỏi về [chủ đề].

[Nội dung]

Cảm ơn cậu trước!

Thân,
[Tên]
```

## Lưu ý đặc thù

- **Không viết tắt** trong email trang trọng (k = không, đc = được, o = ổn)
- **Dấu câu đầy đủ** — viết hoa đầu câu, dùng dấu chấm, dấu phẩy
- **"Dạ" / "Vâng"** cuối câu thể hiện sự tôn trọng — dùng với giảng viên, cấp trên
- **"À" / "ạ"** — sắc thái nhẹ nhàng, không bắt buộc nhưng nên dùng trong email cho giảng viên
- **Zalo chat ≠ email** — không dùng phong cách nhắn tin Zalo để viết email

## Common Mistakes

| Lỗi | Cách sửa |
|-----|----------|
| Xưng "mình" với giảng viên | Dùng "em" — "Thưa Thầy, em muốn hỏi..." |
| Viết tắt "k" thay vì "không" | Viết đầy đủ: "không", "được" |
| Dùng "ok" trong email trang trọng | Dùng "vâng" / "đồng ý" |
| Không có lời chào mở đầu | Luôn bắt đầu bằng "Kính gửi" / "Chào" |
| Kết thư không có "Trân trọng" | Luôn kết thư bằng "Trân trọng," hoặc "Thân ái," |
| Dùng tiếng lóng / ngôn ngữ chat | Giữ văn phong viết chuẩn mực |
