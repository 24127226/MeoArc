# Email Structure

## Overview
Every email is an argument for the reader's attention. A clear structure — subject, opening, body, call to action, closing — respects that attention and gets a faster response. This guide defines the five-part pattern every composed email should follow.

## When to Use
- Composing a new email from scratch
- User says "draft an email to..."
- Rewriting a rambling draft
- User asks "how should I phrase this?"

**Do NOT use** for replies to an existing thread (the thread provides context — use reply_etiquette instead).

## Core Pattern — 5-Part Structure

```
┌─ 1. SUBJECT ──────────────────────────┐
│   [Action] + [Topic] + [Date if needed]│
└────────────────────────────────────────┘
┌─ 2. OPENING ──────────────────────────┐
│   Greeting + context line              │
└────────────────────────────────────────┘
┌─ 3. BODY ─────────────────────────────┐
│   Key information, shortest path       │
└────────────────────────────────────────┘
┌─ 4. CALL TO ACTION ───────────────────┘
│   What the reader should do + by when
└────────────────────────────────────────┘
┌─ 5. CLOSING ──────────────────────────┘
│   Sign-off + full name
└────────────────────────────────────────┘
```

### 1. Subject Line
Formula: `[Action] [Topic] — [Deadline/Context]`

| Type | Pattern | Example |
|------|---------|---------|
| Request | `Request: <topic> — <deadline>` | `Request: Budget approval — due Fri` |
| Meeting | `Meeting: <topic> — <date>` | `Meeting: Sprint retro — Wed 30 Jul` |
| Update | `Update: <topic>` | `Update: Server migration complete` |
| FYI | `FYI: <topic>` | `FYI: Office closure 2 Sep` |
| Question | `Question: <topic>` | `Question: Deadline extension?` |

Keep under 10 words. Never leave the subject blank.

### 2. Opening
One sentence establishing context. The reader should know within 3 words whether this email is about something they know.

| Good | Poor |
|------|------|
| `Following up on our call Tuesday about the deployment...` | `I hope this email finds you well. I am writing to...` |
| `Per your request, here are the Q3 numbers.` | `This is regarding the matter we discussed...` |

**Rule:** No filler openers. No "I hope this email finds you well" — it adds nothing.

### 3. Body
Shortest path to the information. Use:

- **Bullet points** for lists, options, or multiple items
- **Bold** for key numbers or deadlines
- **One paragraph per idea** — max 3 paragraphs
- **Link attachments inline** rather than saying "see attached"

If the body exceeds 5 paragraphs, the email needs to be restructured or the topic needs a document, not an email.

### 4. Call to Action (CTA)
Every email needs exactly one of these:

| CTA Type | Phrasing |
|----------|----------|
| Reply requested | `Please reply by <date>.` |
| Approval needed | `Can you approve this by <date>?` |
| Review requested | `Please review and share feedback by <date>.` |
| Informational | `No action needed — just keeping you posted.` |
| Meeting request | `Does <time> on <date> work for you?` |

If the email genuinely needs nothing, say `No action needed — just for your reference.`

### 5. Closing
Match the tone (see tone_guide):

| Tone | Closing |
|------|---------|
| Formal | `Best regards,` / `Sincerely,` |
| Casual | `Thanks,` / `Cheers,` |
| Intimate | `Talk soon,` |

Always include your full name below the sign-off. Never close without a sign-off line.

## Quick Reference — Email Blueprint

```
Subject: [Action] + [Topic] — [Deadline]

[Greeting] [Name],

[Opening: one-line context]

[Body: key info, bullets if >1 point]

[CTA: what to do + by when]

[Sign-off],
[Full Name]
```

## Common Mistakes

| Mistake | Fix |
|---------|-----|
| No subject or vague subject | Use `[Action] [Topic]` formula |
| "I hope this finds you well" opener | Delete it. Start with context. |
| Multiple CTAs | Pick one. If multiple actions needed, prioritise. |
| Buried deadline | Put the deadline in subject AND CTA |
| No CTA at all | Reader won't know what to do. Always include one. |
| Body too long | Restructure or move detail to an attachment |
